# Getting started

Short, friendly, one step per message. Jesse should be done in a few replies.

## 1. Say what this is (one message)
> This folder is your workshop. From here I can find people near you asking for drain help, make partner packs, prep your partner calls, and look after the Revenue Partner. Three quick setup steps.

## 2. Make the private data folder
If `data/` doesn't exist, create it and copy `templates/data/radar.csv` into it. Tell him: "Your radar list lives in the data folder on this PC only. It's never shared."

## 3. Check the browser
The radar reads Facebook through Jesse's own logged-in browser. Check which browser tool you have (the browser built into the Claude app, or Claude in Edge).
- If one works: open https://www.facebook.com in it. If Facebook asks him to log in, he logs in himself. Confirm you can see his feed (don't scroll it or open anything private).
- If none works: point him at `docs/GUIDE.md` → "Turning on the browser", and carry on with step 4.

## 4. Pick the radar groups
Run the group setup in `radar/groups.md` with him: list the local groups he's already in, let him pick up to 8, write them into the table. Never join a group for him.

## 5. What next
> All set. Next steps, whenever you're ready:
> - "upgrade the Revenue Partner" to add the partner program to it (about five messages, no terminal)
> - "run the radar" to see who's asking for drain help this week
> - "prep a call" before your next partner call
