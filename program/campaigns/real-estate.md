# Campaign template: real-estate agents

**Who sends it:** the agent or their office, from their own email or text system.
**Who to:** their sellers, people thinking of selling, and past clients who bought older homes, as long as the agent is allowed to email or text them.
**When:** spring selling season, or any time an agent has a run of older listings coming up.

Default `[offer]` line (use this if Jesse hasn't set an offer for this campaign):
> If you're not sure whether you need a check, Jesse's happy to talk it through on the phone first.
